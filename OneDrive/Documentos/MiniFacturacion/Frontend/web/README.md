# MiniFacturación FLOG

Sistema de facturación Full-Stack con arquitectura de microservicios.

## Tecnologías usadas
- **Frontend:** React + Vite + TypeScript
- **Backend:** .NET 8 (APIs de Clientes y Facturas)
- **Bases de datos:** SQL Server (Clientes) y MongoDB (Facturas)
- **Librerías:** jsPDF, Recharts, xlsx

## Características
- CRUD de Clientes.
- Creación y visualización de Facturas con cálculo de IVA.
- Catálogo de Productos.
- Dashboard analítico con exportación a Excel.
- Generación de facturas en formato PDF.
